# Fotos de los productos

Una foto por producto, con el nombre del **SKU**: `JOA-001.jpg`, `MAY-001.png`, `JSO-002.webp`...
Al sincronizar el catálogo (**ST Store → Estado → Re-sincronizar catálogo desde los CSV**) la tienda
la usa como imagen destacada. Si un producto no tiene foto, se muestra una imagen referencial con su nombre.

**Cómo prepararla** (para que todas se vean parejas):

- Cuadrada (800 x 800 px), producto centrado sobre fondo blanco, formato JPG, menos de 150 KB.
- Sin teléfonos, logos de otras empresas ni marcas de agua.
- Si la bajas de internet, usa una imagen que puedas reutilizar (catálogo del fabricante, Wikimedia Commons) y anota la fuente
  en `CREDITOS.md`.

**Subir desde GitHub (sin instalar nada):** *Add file → Upload files* dentro de esta carpeta → *Commit changes*.

Las fotos que ya están son referenciales (los modelos pueden diferir del producto vendido); sus fuentes y licencias están en `CREDITOS.md`.
